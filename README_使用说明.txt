MicMuteBridge v1.2.17 Beta — 录制常规切麦快捷键

【安装与试用】
1. 把 ZIP 完整解压到可写的固定目录，例如 D:\Tools\MicMuteBridge。压缩包内已有独立的 MicMuteBridge_v1.2.17_beta 文件夹。保留 v1.2.16 Beta 2 目录以便回退和复制设置。
2. 在新文件夹里双击 CHECK_RELEASE.cmd，看到 RELEASE CHECK PASSED 就通过自检。自检用临时副本核对编译、录制组合、设置迁移、系统映射撤回和内置音效。
3. 在右下角托盘右键旧版 MicMuteBridge，点「退出」。只关闭设置窗口会隐藏到托盘。
4. 把旧版目录的整个 Settings 复制到新版的 START.cmd 旁边。若只有 AppData 里有旧资料，新版首次打开时会复制它们。两处都没有设置时，首次启动使用默认设置。双击新版 START.cmd，本机编译完成后会启动程序。
5. 从托盘打开「详细设置」，确认窗口显示 v1.2.17 Beta。到「音效库 / 音量」分别试听开麦和闭麦，核对已保存的 100ms、音量和裁剪。使用游戏单键时，确认勾选「用扬声器静音键切换麦克风」，用原来的单键测试。
6. 试用通过后，如需自启，在新版设置里勾选「登录 Windows 后自动启动」，把自启指向新版的 EXE。下次登录检查托盘版本。

【数据位置与旧文件迁移】
以下文件夹在 MicMuteBridge.exe 旁边。把程序放 D 盘，程序的数据也随它放在 D 盘。
- Settings 保存 settings.txt、settings.txt.bak 和闭麦诊断记录。自定义提示音在 Settings\Sounds。程序目录的 Sounds 提供编译所需的 12 段内置音效，编译时会把它们写入 EXE。首次用 START.cmd 和以后重新编译时请保留这份 Sounds。正常使用可双击已生成的 MicMuteBridge.exe。
- Logs 保存 MicMuteBridge.log 和上一份轮转日志。历史日志的副本在 Logs\Legacy。
- Errors 保存运行、改键、编译和自检的报错。详细设置底部可以分别打开 Logs 和 Errors。
- 系统单键映射和开机自启由 Windows 注册表记录。以后搬动程序目录时，记得在新位置打开程序并重新设置自启路径。

自动迁移
退出旧版后打开新版 START.cmd。新版的 Settings 文件夹还未建立时，会从 %APPDATA%\MicMuteBridge 复制设置、已有备份、自定义音效和诊断记录，并尝试把两份旧运行日志归档到 Logs\Legacy。旧文件留在原位置供回退。已经准备好的本地 Settings 文件夹优先使用。

手动迁移
1. 退出所有 MicMuteBridge 托盘程序。按 Win+R，输入 %APPDATA%\MicMuteBridge，打开旧数据目录。
2. 把 settings.txt、settings.txt.bak 和 Sounds（如有）复制到新版的 Settings 文件夹。需要保留旧闭麦诊断记录时，也把 mute-recovery.txt 放到 Settings。
3. 想保留旧运行日志，把旧 logs 里面的日志复制到新版 Logs\Legacy。旧安装目录根部的 BUILD_ERROR.log、CHECK_RELEASE_ERROR.log、KEY_MAPPING_ERROR.log 可以归档到新版 Errors\Legacy。
4. 打开新版，核对麦克风选择、100ms 预热、提示音音量和自定义音效。以后升级到同样使用本地设置的版本，在同一台电脑上可先把整个 Settings 文件夹复制到新 EXE 旁边，再启动新版本。

清理旧文件
新版验收通过后，按 Win+R 输入 %APPDATA%，找到其中的 MicMuteBridge 文件夹。可以剪切到 D 盘作为备份，或者在确定无需回退时删除这一个文件夹。如果旧版仍有自启，在新版重新勾选自启，或在旧版退出前先取消自启。如果迁移失败且想从默认设置开始，先把旧数据移到 D 盘备份，再把新版完整解压到一个新的目录后启动。

【托盘与详细设置】
- 右键菜单有五项。开麦 / 闭麦、播放切麦提示音、快捷键设置、详细设置、退出。开麦 / 闭麦一项会随麦克风状态变化，左键点托盘也可以切麦。
- 旧菜单「暂停系统静音键桥接」旁的勾表示功能正在启用，点击才会暂停。现在到「详细设置」勾选「用扬声器静音键切换麦克风」。按系统静音键时，程序会自动恢复扬声器并切换麦克风。取消勾选后，这个键只控制扬声器。设置即时生效。
- 麦克风选择、控制全部设备、确认打开全部麦克风、开机自启和日志都在「详细设置」。音效试听在「详细设置」→「音效库 / 音量…」。无预热对照在音效库底部。

【设置快捷键】
右键托盘图标 →「快捷键设置…」。「详细设置」右上角也能打开。

游戏单键 · 系统静音触发
- MicMuteBridge 检测到 Windows 扬声器静音后，自动恢复扬声器并切换麦克风。该触发方式已在国服 LOL 全屏验证。
- 点「录制单键…」，按下想用的键，松开后下拉框就会选中它。字母、数字、标点、方向键、空格、Esc、左右 Ctrl 和小键盘都可以试。Windows 能报出可映射扫描码的单键可直接录制，常用的预设也可从下拉框选。要取消录制，用鼠标点「取消」。
- 小键盘 7 和独立 Home 是两枚键。Num Lock 开关都对应同一枚小键盘实体键。部分键盘的 Fn 由硬件处理，Windows 收不到。Pause 的扫描码超出了 Windows 这张改键表的格式。
- 选好后点「应用系统单键…」，同意 Windows 管理员授权并重启。选中的键会在整台电脑变成扬声器静音，适合选登录和日常操作都少用的一枚。已保存的游戏单键可从列表选回。Windows 已经改过的其他键会按改键后的信号被识别，应用前请核对显示的键名。
- 之前用免安装小工具设置的 Home 可以在这里直接换键或撤回。应用新键时只替换本工具先前写入的规则。其他工具设置的键位保留。
- 点「撤回系统单键…」并重启可恢复原键。键盘已有扬声器静音键时，可以直接用那个键。
- 如果在另一台电脑上试新映射，先暂停 PowerToys 键盘管理器，并在「详细设置」取消勾选「用扬声器静音键切换麦克风」。按所选键，确认 Windows 扬声器静音，再按一次恢复。重新勾选后，再进国服 LOL 全屏实测。

常规开关麦克风
- 点「录制快捷键…」，同时按住想用的一组键，确认显示齐全后全部松开。可以录 J + K、三个或四个普通键、单独一枚鼠标侧键，也可以混搭键盘和侧键。点「保存快捷键」，再点「完成」即可使用。录制需要在录制窗口保持焦点，取消请用鼠标点「取消」。
- 常规快捷键默认关闭。已保存的旧组合键仍可使用，也可重新录制。点「关闭快捷键」可停用。新录制的快捷键也会传给当前应用，例如浏览器仍会响应侧键的后退动作。设置文件只保存选定的组合，运行日志记录切麦和报错。
- 同时按下保存的整组键触发一次，全部松开后可再次触发。键盘必须能同时上报这些键。鼠标需能上报标准侧键 1 / 2。由硬件处理的 Fn、缺少正常按下和松开事件的 Pause，以及会让录制窗口失去焦点的 Windows 快捷键，可能无法录制。按住时可先看录制窗口有没有显示全。
- 使用不同的键设置两种切麦方式。扬声器静音键留给上方游戏单键。常规快捷键适用于桌面和一般应用。国服 LOL 全屏请使用原有游戏单键。

【保存与编译保护】
- 设置完整写入临时文件后再更新 settings.txt。有效的上一份配置存为 settings.txt.bak。主设置缺失、读不出或损坏时会读取有效备份。如果两份都没有完整配置，仍会保留可读的项目。
- 编译使用 Windows 随 .NET Framework 提供的 C# 编译器，在同目录下的临时子文件夹完成。核对 12 段内置音效都写入新 EXE 后才替换原 EXE。若有文件缺失，Errors\BUILD_ERROR.log 会指出具体文件。请从 ZIP 补齐程序目录里的 Sounds，再双击 START.cmd。同目录原来有可用 EXE 时，可以直接双击那份运行。

【登录后的音频连接】
如果程序启动时无法连接 Windows 音频，托盘和设置会显示「等待 Windows 音频」，程序约每 2 秒自动重试。
设置里麦克风旁边的「刷新」可以立即尝试连接。连上后会检查 Windows 默认输出和原有设置选定的麦克风，读取它们的实际静音状态。
运行日志会记录音频连接失败和恢复的情况。

【全部模式】
设备都正常时，有麦开着就统一闭麦，全部闭麦时再按一次统一开麦。
设备状态读不全时，已静音的麦克风保持静音。若本次方向是闭麦，程序仍会尝试关闭已读到的设备。
如果统一开麦进行到一半遇到失败，程序会停下剩余开麦操作。同一组设备恢复可读、还有麦克风静音时，可以再按一次重试。
「详细设置」中麦克风选择区域的「确认打开全部麦克风…」在确认后也会检查全部活动设备的状态。
开机或手动打开程序时先读取麦克风的实际状态。上次闭麦记录只供诊断。只有本次运行中主动发起闭麦后，新接入设备才会进入原有的自动闭麦流程。
只有确认全部设备已达到目标状态才播放正常成功音效。部分设备失败时请看「麦克风明细」和运行日志。

【Windows 验收】
每台电脑先跑一次 CHECK_RELEASE.cmd，再打开新版。
迁移验收时先看 Settings 和 Logs 是否出现在 EXE 旁边。打开音效库试听，核对原来的麦克风、预热、音量和裁剪。左键切麦后，确认本地 Logs\MicMuteBridge.log 有新增记录。
1. 右键托盘，确认只有五项。用右键菜单闭麦，用托盘左键恢复。切换「播放切麦提示音」并打开详细设置，检查两个入口的勾选状态同步。
2. 取消勾选「用扬声器静音键切换麦克风」，用原游戏单键试扬声器静音，再按一次恢复扬声器。重新勾选，用同一枚键切麦。打开音效库试开麦、闭麦和无预热试听。在全部模式点「确认打开全部麦克风…」，选择「否」，确认麦克风状态与操作前一致。
3. 改一个容易辨认的提示音音量并点「应用音量」。从托盘退出后重新打开 MicMuteBridge.exe，确认音量、静音键切麦开关和原有裁剪仍正确，再把音量调回平时的值。
4. 在「常规开关麦克风」分别试录 J + K、三四个键、鼠标侧键和键盘加侧键。全部松开后核对显示。保存一组后点「完成」，到录音机测试按住只切一次、全部松开后再按能恢复。关闭快捷键后确认停用，重开程序确认保存状态。保留原有游戏单键，直接在全屏里验证切麦。
5. 在有三支活动麦克风的电脑上，先用指定模式静音 Mix 01，确认另外两支开启，再切到全部模式。切麦两次，静音数应从 1/3 变 3/3 再变 0/3。全部静音后退出再打开程序，先看状态，三支应保持静音。
6. 主机开关 Studio One 各一次，确认设置里的默认输出跟着 Windows 改变。关闭 BGM 后用 100ms 试听开麦和闭麦，核对预设、自定义音效和裁剪。再请队友在国服 LOL 全屏语音里确认游戏单键能开麦、闭麦、开麦。
7. 第二台台式按上面的步骤验证所选系统单键，再进国服 LOL 全屏测试。笔记本用内置麦克风和扬声器试托盘切换，再试现有的多媒体静音键。
8. 点一次「刷新」，确认麦克风的静音状态与刷新前一致。勾选新版自启后重新登录 Windows，确认托盘显示 v1.2.17 Beta，并再试一次切麦。若显示「等待 Windows 音频」，等设备名称恢复后再试，日志中可查看失败和恢复。

【提示音用法】
- 在「音效库 / 音量…」中分别选择开麦和闭麦声音。拖动 0–100% 滑块后点「应用音量」，再点「试听」。100% 是原始音量，0% 是无声。音量只作用于提示音。
- 点对应行的「裁剪…」，输入起点和终点，最短保留 20ms。裁剪只修改播放范围，原 WAV 文件保持原样。换音效或重新导入会重置对应裁剪范围。
- 自定义音效可导入未压缩的单声道或双声道 PCM WAV、32-bit Float WAV，最长 3 秒。预置的经典提示音为 220ms。
- 预热档位是 0、100、150、200、250、300、450、650ms。已有设置里存下的 100ms 会继续读取，空配置使用 300ms。预热是提示音开头的静音，麦克风先切换。
- 提示音沿 Windows 的播放路由输出。用虚拟声卡时，可以回听录音来确认提示音是否经 Mix 01 回环送进语音。

【日志与回退】
自检失败时，发 Errors\CHECK_RELEASE_ERROR.log。编译失败时，发 Errors\BUILD_ERROR.log。改键失败时，查看 Errors\KEY_MAPPING_ERROR.log。运行问题先看 Logs\MicMuteBridge.log 和 Errors\RUNTIME_ERROR.log（有运行错误时生成）。
回退时从托盘退出 v1.2.17，打开原来的 v1.2.16 Beta 2 目录。各版本使用各自目录的 Settings。若已切换过自启，请在旧版的设置重新勾选。想恢复某枚键的原用途，可用「撤回系统单键…」并重启。

本包是源码测试版。Windows 编译、实体键鼠录制、开麦 / 闭麦和国服 LOL 全屏实测请按上述步骤完成。
