# 🎙️ MicMuteBridge-LOL

专为 **国服《英雄联盟》(LOL) 全屏模式** 及日常桌面语音打造的轻量级麦克风一键静音工具。

针对国服 LOL 全屏下反作弊系统拦截普通全局热键导致无法切麦的痛点，本工具提供 **「系统扬声器静音桥接」** 与 **「桌面多键 / 鼠标侧键录制」** 双模式，自带无延迟提示音与波形裁剪功能。

> 🤖 **AI 编码透明度说明**：本项目由作者提供核心思路与实机测试，借助 **Gemini** 与 **GPT** 协作完成代码构建与审查。程序完全本地运行、无任何联网行为，源码单文件完全公开；如您介意 AI 辅助编写的代码，请知悉并按需取用。

## 📥 下载与使用（普通玩家）

**无需下载源码！** 请直接点击右侧的 **[Releases](https://github.com/Toastcat0v0/MicMuteBridge-LOL/releases)**，下载最新版的压缩包，解压后双击 **`MicMuteBridge.exe`** 即可开袋即食！

## ✨ 核心特性

* 🎮 **全屏游戏单键切麦（已验证国服 LOL 全屏）**：将指定闲置单键映射为 Windows 系统扬声器静音信号，软件捕获信号后**毫秒级恢复扬声器并切换麦克风状态**，绕过全屏反作弊热键拦截。
* ⌨️ **常规桌面快捷键 & 鼠标侧键**：支持录制单键、多键组合（如 `J + K`）以及鼠标侧键 1 / 2（支持键鼠混搭），适合桌面与常规应用。
* 🔊 **内置 6 套合成提示音 & 自定义 WAV**：内置经典、柔和气泡、像素按键、清脆铃音、水滴弹跳、电子科技 6 套音效；支持导入本地 WAV、独立调节提示音音量（0~100%，不影响系统/游戏音量）、毫秒级裁剪及声卡防吞音预热。
* 📦 **单文件绿色便携**：单 EXE 即可独立运行，配置与日志保存在程序旁，不污染系统盘。

## 💡 实用小贴士

由于「游戏单键」利用了系统扬声器静音做跳板，按键时会闪出 Windows 音量指示浮窗。若觉得挡左上角小地图视线，可在 **Windows 设置 -> 系统 -> 通知 -> 键盘操作的指示器 -> 屏幕指示器的位置** 中，将其修改为「底部居中」或「顶部居中」。

## 🛠️ 从源码编译（开发者）

无需安装 Visual Studio，直接调用 Windows 自带的 .NET Framework C# 编译器即可构建：
1. 下载完整源码（确保 `Sounds` 目录下的 12 个 `.wav` 文件完整）。
2. 双击 `CHECK_RELEASE.cmd` 执行自动化构建与自检。
3. 双击 `BUILD.cmd` 或 `START.cmd` 编译生成 `MicMuteBridge.exe`。
